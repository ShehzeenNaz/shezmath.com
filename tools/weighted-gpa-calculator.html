How It Works

Formula: Weighted GPA = total weighted grade points ÷ total credits. Each course earns (grade value + course bonus) × credits, where the bonus is +1.0 for AP, +0.5 for Honors and 0 for Regular. Grade values are A = 4, B = 3, C = 2, D = 1, F = 0.

Worked example: Four courses: A in a Regular class (3 credits), B in an AP class (3 credits), A in an Honors class (4 credits) and C in a Regular class (3 credits). Weighted points are 4.0 × 3 = 12, (3.0 + 1.0) × 3 = 12, (4.0 + 0.5) × 4 = 18 and 2.0 × 3 = 6. That is 12 + 12 + 18 + 6 = 48 weighted points over 13 credits. 48 ÷ 13 = 3.69. Your weighted GPA is 3.69.

Frequently Asked Questions

How much bonus does an AP course add?

An AP course adds 1.0 grade point. So a B in an AP class is worth 4.0 points, the same as an A in a regular class, and an A in an AP class is worth 5.0.

How much bonus does an Honors course add?

An Honors course adds 0.5 grade points. So a B in an Honors class is worth 3.5 points and an A in an Honors class is worth 4.5.

What is the highest possible weighted GPA?

With a 1.0 AP bonus, the highest weighted GPA is 5.0, earned by getting an A in every AP course. Most students fall between 3.0 and 4.5.

Do colleges use weighted or unweighted GPA?

Many colleges look at both. They often recalculate your GPA on their own scale so students from different schools can be compared fairly. Your transcript usually shows both figures.
