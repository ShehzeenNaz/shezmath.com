Turn a percentage mark into a GPA on the 4.0 scale using the standard band table. Enter your percentage to see your GPA and letter grade at once.

How It Works

Formula: Your percentage is matched to a band on the standard 4.0 scale: 93–100 = 4.0, 90–92 = 3.7, 87–89 = 3.3, 83–86 = 3.0, 80–82 = 2.7, 77–79 = 2.3, 73–76 = 2.0, 70–72 = 1.7, 67–69 = 1.3, 63–66 = 1.0, 60–62 = 0.7, below 60 = 0.0.

Worked example: Your mark is 88%. Look up the band table: 88% falls in the 87–89 band, which is a 3.3 GPA (a B+). So 88% converts to a 3.3 GPA.

Frequently Asked Questions

What GPA is 90%?

On the standard band table, 90 to 92% converts to a 3.7 GPA, which is an A minus. A 93% or higher converts to a full 4.0 GPA.

Is this band table used by every university?

No. This is the widely used standard 4.0 band table, but some schools use different cutoffs. Always check your own university's grading scale for official conversions.

What GPA is a pass at 60%?

On this table, 60 to 62% converts to a 0.7 GPA. Anything below 60% converts to a 0.0 GPA, which is a fail.

Can I convert an average percentage for a whole semester?

You can, but it is only an estimate. A true semester GPA weights each course by its credit hours, so use the GPA calculator for an exact result.
