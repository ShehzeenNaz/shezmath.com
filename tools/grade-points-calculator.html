Grade Points Calculator

Convert a letter grade into grade points for one course. Pick your letter grade and the course credits to see how many points you earned.

Your numbers never leave your device. All calculations happen in your browser.

How It Works

Formula: Grade points earned = grade point value × credits. The standard 4.0 scale is A+ = 4.0, A = 4.0, A− = 3.7, B+ = 3.3, B = 3.0, B− = 2.7, C+ = 2.3, C = 2.0, C− = 1.7, D+ = 1.3, D = 1.0, F = 0.

Worked example: You earned an A− in a 3-credit course. An A− is worth 3.7 grade points per credit. Multiply 3.7 by 3 credits to get 11.1. You earned 11.1 grade points from this course.

Frequently Asked Questions

What are grade points?

Grade points are the number you get when you multiply a grade point value by the credits of a course. For example, an A minus is worth 3.7 points, so in a 3-credit course it earns 3.7 times 3, which is 11.1 grade points.

How many grade points is an A worth?

An A is worth 4.0 grade points per credit, the same as an A plus. So an A in a 3-credit course earns 12 grade points, while an A minus at 3.7 earns 11.1.

What grade point value does an F have?

An F is worth 0 grade points, so it earns no points no matter how many credits the course carries, and it still counts in your GPA.

How do grade points turn into a GPA?

Add up the grade points from all your courses, then divide by the total number of credits. That result is your GPA on the 4.0 scale.
